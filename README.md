# British Prestige Cleaning Solutions

A modern, high-performance web application and booking platform for a premium UK-based cleaning service. Built with Next.js, Prisma, PostgreSQL, and Docker.

---

## 🏗️ Architecture & Tech Stack

- **Frontend & Framework:** [Next.js 15](https://nextjs.org/) (App Router) with React 19
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Database:** PostgreSQL
- **ORM:** [Prisma v6](https://www.prisma.io/)
- **Authentication:** [NextAuth.js (Auth.js)](https://authjs.dev/) with bcrypt
- **Deployment:** Docker & Docker Compose (Nginx reverse proxy + Next.js Standalone + Postgres)

## 🚀 Local Development Setup

To run this project locally, you will need **Node.js (v20+)** and **Docker** installed on your machine.

### 1. Clone the repository
```bash
git clone <repository-url>
cd britishprestigecleaning
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Environment Variables
Duplicate the `.env.example` file and rename it to `.env`. Ensure the local database connection is set up:
```env
# Example Local .env
DATABASE_URL="postgresql://bpcleaning:bpcleaning_secret_2024@localhost:5432/britishprestigecleaning"
NEXTAUTH_SECRET="your-random-secret-key"
NEXT_PUBLIC_SITE_URL="http://localhost:3000"
```

### 4. Start the Local Database
We use Docker to spin up the local PostgreSQL database:
```bash
docker compose up -d postgres
```

### 5. Initialize the Database
Push the database schema and seed it with initial data (Site Settings, Services, and Admin User):
```bash
npx prisma db push
npm run db:seed
```
*Note: The default admin credentials are generated by the seed script (Check `prisma/seed.ts` for details).*

### 6. Start the Development Server
```bash
npm run dev
```
The site will now be accessible at [http://localhost:3000](http://localhost:3000).

## 🚢 Production Deployment Workflow

The application is fully containerized using Docker, making it highly portable and easy to deploy on any Ubuntu VPS (EC2, DigitalOcean, etc.).

### 1. Transfer Code to the Production Server
Use `rsync` to securely copy the codebase to your production server (excluding heavy dev folders):
```bash
rsync -avz --exclude 'node_modules' --exclude '.next' --exclude '.git' ~/british-prestige-cleaning/ root@<YOUR_VPS_IP>:~/british-prestige-cleaning/
```

### 2. Server Setup (Ubuntu)
SSH into your production server:
```bash
ssh root@<YOUR_VPS_IP>
```
Install Docker (if not already installed):
```bash
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh
```

### 3. Environment Variables
Create or update the `.env` file on the production server. Be sure to set the exact live domain:
```bash
echo 'NEXT_PUBLIC_SITE_URL="https://bpcs.shop"' >> .env
```

### 4. Build and Start the Application
Run Docker Compose in detached mode. This will build the highly optimized Next.js standalone image, start the PostgreSQL database, and spin up the Nginx proxy:
```bash
docker compose up -d --build
```

### 5. Initialize the Production Database
Because the production container does not contain development dependencies, run a temporary container on the host network to push the schema and seed the database securely:
```bash
docker run --rm --network host \
  -e DATABASE_URL="postgresql://bpcleaning:bpcleaning_secret_2024@localhost:5432/britishprestigecleaning" \
  -v $(pwd):/app -w /app node:20 sh -c "\
  npm install --legacy-peer-deps && \
  npx prisma@6 db push && \
  npx tsx prisma/seed.ts"
```

## 🔒 SSL & Domain Configuration

To secure the site with HTTPS, we use Let's Encrypt (Certbot) and map the certificates into our Nginx container.

1. **DNS Setup:** Point your domain's `A` record to your server's IP address. Wait for propagation.
2. **Install Certbot:**
   ```bash
   apt update && apt install -y certbot
   ```
3. **Stop Docker momentarily to free port 80:**
   ```bash
   docker compose down
   ```
4. **Generate Certificate:**
   ```bash
   certbot certonly --standalone -d bpcs.shop -d www.bpcs.shop
   ```
5. **Nginx & Docker Config:** 
   - Ensure `nginx/default.conf` redirects Port 80 to 443 and points to the `/etc/letsencrypt/` paths.
   - Ensure `docker-compose.yml` mounts the `/etc/letsencrypt` volume and exposes port `443`.
6. **Restart Services:**
   ```bash
   docker compose up -d --build
   ```

## 📂 Project Structure Highlights

- `/app` - Next.js App Router containing all pages, API routes, and layouts.
- `/components` - Reusable React components (UI elements, marketing sections, etc.).
- `/prisma` - Database schema (`schema.prisma`) and seeding script (`seed.ts`).
- `/lib` - Utility functions, constants (`constants.ts` where business details are defined), and database client.
- `/nginx` - Custom Nginx configuration for the reverse proxy.
- `Dockerfile` - Multi-stage build process generating the minimal standalone Next.js image.
- `docker-compose.yml` - Defines the orchestration of the Web, DB, and Proxy containers.
